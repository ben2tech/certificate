# ระบบค้นหาเกียรติบัตรออนไลน์

## ไฟล์ในระบบ
- `index.html` — หน้าให้นักเรียนกรอกรหัสค้นหาเกียรติบัตร
- `admin.html` + `admin.js` — หน้าแอดมิน (ล็อกอิน, อัปโหลดพื้นหลัง, ลากวางตำแหน่งข้อความ, จัดการรายชื่อนักเรียน)
- `config.js` — เก็บค่าเชื่อมต่อ Supabase (ใส่ให้แล้ว)
- `render.js` — โค้ดกลางสำหรับวาดเกียรติบัตรลง canvas
- `styles.css` — ธีมหน้าตาเว็บ
- `setup.sql`, `setup2.sql` — คำสั่งสร้างตารางฐานข้อมูล (รันใน Supabase ไปแล้ว/ต้องรันถ้ายังไม่ได้ทำ)

## สิ่งที่ต้องทำใน Supabase ก่อนใช้งาน

1. **รัน SQL**: ไปที่ SQL Editor รันไฟล์ `setup.sql` แล้วรัน `setup2.sql` ตามลำดับ (ถ้ายังไม่เคยรัน)
2. **สร้าง Storage bucket**: Storage → New bucket → ตั้งชื่อ `certificates` → เปิด **Public bucket**
3. **สร้างบัญชีแอดมิน**: ไปที่เมนู **Authentication** → **Users** → **Add user** → ใส่อีเมลและรหัสผ่านของแอดมิน (ใช้ล็อกอินหน้า admin.html)
   - ติ๊ก "Auto Confirm User" ด้วย ไม่งั้นต้องยืนยันอีเมลก่อนถึงจะล็อกอินได้

## วิธีใช้งาน

### หน้าแอดมิน (admin.html)
1. ล็อกอินด้วยอีเมล/รหัสผ่านที่สร้างไว้
2. แท็บ **เทมเพลตเกียรติบัตร** → "+ สร้างเทมเพลตใหม่" → อัปโหลดรูปพื้นหลัง
3. คลิกบนรูปเพื่อวางช่องข้อความ (เช่น ชื่อ-นามสกุล) แล้วลากป้ายไปยังตำแหน่งที่ต้องการ
4. เลือกช่องทางด้านซ้าย (field list) เพื่อปรับ ขนาด/สี/การจัดวาง/น้ำหนักตัวอักษร
5. กด "บันทึกเทมเพลต"
6. แท็บ **รายชื่อนักเรียน** → "+ เพิ่มนักเรียน" ใส่รหัส-ชื่อ-เลือกเทมเพลต หรือใช้ "นำเข้าจาก CSV" (เลือกเทมเพลตในตัวกรองก่อน แล้วไฟล์ CSV ต้องมีหัวคอลัมน์ `student_code,name` และคอลัมน์อื่นตามฟิลด์เพิ่มเติมที่ตั้งไว้)

### หน้านักเรียน (index.html)
กรอกรหัสนักเรียน → ระบบแสดงเกียรติบัตร → กดดาวน์โหลดเป็นรูปภาพได้ทันที

## วิธีอัปโหลดขึ้น GitHub Pages

1. สร้าง repository ใหม่บน GitHub (public หรือ private ก็ได้)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น repo (ลาก-วางผ่านหน้าเว็บ GitHub ได้เลย ไม่ต้องใช้ command line)
3. ไปที่ repo → **Settings** → **Pages**
4. ที่ **Source** เลือก branch `main` และโฟลเดอร์ `/ (root)` → กด **Save**
5. รอสักครู่ จะได้ลิงก์เว็บ เช่น `https://ชื่อผู้ใช้.github.io/ชื่อ-repo/`
   - หน้านักเรียน: `.../index.html`
   - หน้าแอดมิน: `.../admin.html`

เว็บนี้เป็น responsive design เปิดได้ทั้งคอมพิวเตอร์ มือถือ และ iPad โดยไม่ต้องทำแอปแยก
